# Grapevine Disease Dataset with Metadata

## Overview
This dataset contains **3,477 grapevine images** categorized into four classes:
1. **Healthy**
2. **Black Rot**
3. **Esca**
4. **Leaf Blight**

Each entry is accompanied by detailed metadata stored in `metadata.json`, including:
- **Location**: Vineyard name and GPS coordinates
- **Environmental Conditions**: Time of capture, lighting, and weather notes
- **Plant Health Status**: Healthy or Diseased
- **Disease Type**: One of the four categories
- **Device Specifications**: Device model, sensor, and OS details

The dataset is suitable for research in:
- Plant disease detection using AI/ML
- Remote sensing for agriculture
- Precision viticulture
